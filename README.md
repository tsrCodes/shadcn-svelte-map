# shadcn-svelte Map

Map components for [shadcn-svelte](https://shadcn-svelte.com), built on [MapLibre GL](https://maplibre.org). View and edit maps: markers, popups, routes, clusters, heatmaps, drawing, place search and more. Copy-paste install, themed with your shadcn tokens, no API key.

> **Work in progress.** Not ready for use yet.

## Installation

```bash
pnpm dlx shadcn-svelte@latest add https://shadcn-svelte-map.vercel.app/r/map.json
```
